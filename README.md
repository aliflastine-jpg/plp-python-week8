
# PLP Python Week 8 - Personal Toolkit

## Project Description

This project is a personal Python toolkit containing three useful tools:

1. Simple Calculator - Performs addition, subtraction, multiplication and division.
2. To-Do List - Allows users to add, view and remove tasks.
3. Number Guessing Game - Allows users to guess a randomly selected number.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

python toolkit.py

5. Choose a tool from the menu.

## Python Concepts Used

- Loops
- Lists
- Conditional statements
- Functions
- User input
- F-strings
- Exception handling

## Reflection

The hardest part of this project was connecting all three tools to one main menu. I had to understand how loops and conditional statements work together. The most challenging bug was handling invalid user input without crashing the program. I solved this by using try and except blocks. I also learned how to use lists to store and remove tasks. This project improved my understanding of Python functions, loops and decision-making. With one more week, I would add more tools such as a countdown timer and a student grade calculator.
